# Tap

Children and parents scan a QR code attached to a printed object, then tap one large control to hear a short character sound. Each page has its own stable URL, theme and sound set. Named controls allow the parent to audition candidate clips before accepting a set. Pikachu is the first character. Eevee remains a separate production site with existing QR codes.

The implementation is a dependency-free static site generated from JSON and hosted on GitHub Pages. No user data, accounts or backend. Phone audio acceptance needs physical listening.
