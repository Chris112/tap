# Tap player

Preserve the existing Eevee interaction: a central circular tap control, themed background and ring, clear hint below. Pikachu uses warm yellow and brown. The generic demo uses green. Use the incumbent rounded system font stack, rather than introducing an unrelated visual identity.

Pikachu displays only the character heading, large play control and animated playback indicator. Its status remains available to screen readers. Detailed pages such as the demo can also display status text and named sound buttons. Allow vertical scrolling on short phones. Respect reduced motion and expose keyboard focus and live playback status. Source or implementation details belong in repository documentation, not the child-facing page.
