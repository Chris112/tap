# Tap player

Preserve the existing Eevee interaction: a central circular tap control, themed background and ring, clear hint below. Pikachu uses warm yellow and brown. The generic demo uses green. Use the incumbent rounded system font stack, rather than introducing an unrelated visual identity.

Pages display a character heading, the large play control, a small playback indicator, status text and optional named sound buttons. Allow vertical scrolling on short phones. Respect reduced motion and expose keyboard focus and live playback status. Source or implementation details belong in repository documentation, not the child-facing page.
